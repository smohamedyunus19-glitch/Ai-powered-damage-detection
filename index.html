About Fix Nearby

Fix Nearby is an AI-powered device damage detection platform built as an academic project. It uses YOLOv8 deep learning models to identify damage in mobile phones and laptops from a single photo, then connects users with nearby repair shops using OpenStreetMap.

Domain: Artificial Intelligence & Computer Vision
Technology: YOLOv8, Flask, MongoDB, OpenStreetMap
Models: Mobile (62.2% mAP50) · Laptop (48.6% mAP50)

YOLOv8 Flask API MongoDB OpenStreetMap Computer Vision Deep Learning
